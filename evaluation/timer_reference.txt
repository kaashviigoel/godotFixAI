GODOT 4 TIMER REFERENCE

For a Node with a child Timer named Timer:

extends Node

@onready var timer: Timer = $Timer

func _ready() -> void:
    timer.wait_time = 2.0
    timer.timeout.connect(_on_timer_timeout)
    timer.start()

func _on_timer_timeout() -> void:
    print("Timer fired!")

Checks:
1. A Timer child exists at the path $Timer.
2. The timer is not paused and wait_time is positive.
3. timer.start() is called.
4. Check the Output panel for "Timer fired!" after two seconds.

Godot 4 signals use signal.connect(callable), for example:
timer.timeout.connect(_on_timer_timeout)

Do not use Godot 3 syntax such as:
connect("timeout", self, "_on_timer_timeout")
